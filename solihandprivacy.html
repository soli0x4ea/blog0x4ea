中文

Soli Hand 尊重并保护您的隐私

本 App 不会向任何服务器收集、存储或传输您的个人数据。以下是具体说明：

  • 不含任何分析统计、广告追踪或崩溃上报 SDK；
  • 不向任何远程服务器发起网络请求。所有输入逻辑与界面均在您的设备本地运行；与 Soli Hand 设备的通信仅通过本地低功耗蓝牙（BLE）完成，不经过互联网；
  • 无账号体系，不读取设备标识符（如 IDFA / identifierForVendor）、位置或通讯录；
  • 不接入任何第三方 SDK（SoliHandLink 为开发者自研的本地代码包，不含网络功能）；
  • 您的输入（按键、鼠标 / 触控板移动、手柄操作）会实时通过本地 BLE 链路仅发往已配对的 Soli Hand 设备，用于驱动该设备作为电脑输入外设。这些输入不会被存储于手机、不会上传到任何服务器，开发者也无法访问；
  • 语言偏好与输入调参（指针速度、摇杆灵敏度、滚轮灵敏度等）仅存储于设备本地（UserDefaults），不会离开设备；
  • App 仅请求蓝牙权限，用途为连接 Soli Hand 设备，把手机变成电脑的触控板、键盘与手柄。

本 App 不含面向儿童收集数据的功能，年龄分级为 4+。

若日后版本变更数据处理方式，我们将在本页面更新说明。

English

Soli Hand respects and protects your privacy

The app does not collect, store, or transmit any of your personal data to any server. Details below:

  • No analytics, ad-tracking, or crash-reporting SDKs of any kind;
  • No network requests to any remote server. All input logic and UI run locally on your device; communication with the Soli Hand device happens only over local Bluetooth Low Energy (BLE) and never goes over the internet;
  • No account system; no access to device identifiers (such as IDFA / identifierForVendor), location, or contacts;
  • No third-party SDKs embedded (SoliHandLink is a local code package authored by the developer and contains no networking functionality);
  • Your input (keystrokes, mouse / trackpad movement, gamepad actions) is sent in real time over the local BLE link only to the paired Soli Hand device, so that device can act as a computer input peripheral. This input is not stored on the phone, is not uploaded to any server, and is not accessible to the developer;
  • Your language preference and input tuning settings (pointer speed, stick sensitivity, scroll sensitivity, etc.) are stored only on-device (UserDefaults) and never leave the device;
  • The app requests only Bluetooth permission, used to connect to the Soli Hand device and turn your phone into a trackpad, keyboard, and gamepad for your computer.

The app includes no features that collect data from children; age rating is 4+.

If a future version changes how data is handled, this page will be updated.
